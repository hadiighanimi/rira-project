# 💱 پروژه تبدیل‌کننده ارز

> یک وب‌اپلیکیشن مدرن، واکنش‌گرا و Type-Safe برای تبدیل دوطرفه دلار آمریکا (USD) و ریال ایران (IRR)

---

## 🚀 نحوه اجرای پروژه

### پیش‌نیازها

برای اجرای پروژه در محیط محلی، موارد زیر باید روی سیستم نصب باشند:

- **Node.js**
- **npm**

---

### 1️⃣ دریافت پروژه

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/hadiighanimi/rira-project.git
```

---

### 2️⃣ ورود به پوشه پروژه

```bash
cd rira-project
```

---

### 3️⃣ نصب وابستگی‌ها

```bash
npm install
```

---

### 4️⃣ اجرای پروژه در حالت توسعه

```bash
npm run dev
```

پس از اجرای این دستور، پروژه توسط **Vite Development Server** اجرا می‌شود و آدرس اجرای محلی در ترمینال نمایش داده خواهد شد.

## 👀 مشاهده نسخه Production

برای بررسی نسخه Production در محیط محلی:

```bash
npm run preview
```

این دستور نسخه Build شده پروژه را با استفاده از Preview Server اجرا می‌کند.

# 📌 معرفی پروژه

**Rira Currency Converter** یک وب‌اپلیکیشن Front-End است که با استفاده از **React، TypeScript و Vite** توسعه داده شده است.

هدف پروژه، پیاده‌سازی یک تبدیل‌کننده ارز ساده، سریع و کاربردی است که کاربر بتواند مقدار موردنظر خود را وارد کرده و معادل آن را در واحد ارزی دیگر، **به‌صورت لحظه‌ای و بدون نیاز به بارگذاری مجدد صفحه** مشاهده کند.

در طراحی و پیاده‌سازی پروژه، علاوه بر عملکرد اصلی، موارد زیر نیز مورد توجه قرار گرفته‌اند:

- تجربه کاربری مناسب
- طراحی واکنش‌گرا
- ساختار Component-Based
- Type Safety
- جداسازی منطق محاسباتی از رابط کاربری
- خوانایی و قابلیت نگهداری کد

---

# ✨ قابلیت‌های پروژه

## 🔄 تبدیل دوطرفه ارز

امکان تبدیل هر دو جهت بین:

- 💵 **دلار آمریکا (USD) → ریال ایران (IRR)**
- 💴 **ریال ایران (IRR) → دلار آمریکا (USD)**

کاربر می‌تواند مقدار موردنظر را در هر یک از ورودی‌ها وارد کند و مقدار معادل در واحد ارزی مقابل به‌صورت خودکار محاسبه شود.

---

## ⚡ محاسبه لحظه‌ای

با هر تغییر در مقدار ورودی، نتیجه تبدیل بلافاصله به‌روزرسانی می‌شود.

برای مشاهده نتیجه نیازی به:

- Refresh صفحه
- ارسال فرم
- کلیک روی دکمه محاسبه

وجود ندارد.

تمام محاسبات در سمت Client انجام می‌شوند.

---

## 🔢 فرمت‌دهی خودکار اعداد

برای افزایش خوانایی مقادیر، اعداد با **جداکننده سه‌رقمی** نمایش داده می‌شوند.

برای مثال:

```text
1000000
↓
1,000,000
```

این قابلیت باعث می‌شود کاربر بتواند مقادیر بزرگ را سریع‌تر و دقیق‌تر تشخیص دهد.

---

## 📱 طراحی واکنش‌گرا

رابط کاربری برای نمایش صحیح در اندازه‌های مختلف صفحه طراحی شده است.

پروژه در:

- 💻 دسکتاپ
- 📱 موبایل
- 📟 تبلت

قابل استفاده است.

برای پیاده‌سازی Responsive Design از قابلیت‌های مدرن CSS مانند موارد زیر استفاده شده است:

- `Flexbox`
- `CSS Variables`
- `clamp()`
- واحدهای نسبی

---

## 🧩 ساختار Component-Based

ساختار پروژه بر اساس Componentهای مستقل طراحی شده است.

این رویکرد باعث می‌شود:

- خوانایی کد افزایش پیدا کند.
- نگهداری پروژه ساده‌تر شود.
- تغییرات یک بخش تأثیر کمتری روی سایر بخش‌ها داشته باشد.
- توسعه قابلیت‌های جدید آسان‌تر شود.
- امکان استفاده مجدد از Componentها وجود داشته باشد.

---

## 🛡️ Type Safety با TypeScript

برای تعریف ساختار داده‌ها و کاهش خطاهای مربوط به Type از **TypeScript** استفاده شده است.

Typeها و Interfaceهای موردنیاز پروژه در بخش مجزایی قرار گرفته‌اند تا ساختار داده‌ها در قسمت‌های مختلف برنامه یکپارچه باقی بماند.

# 🏗️ ساختار پروژه

ساختار پروژه با هدف **جداسازی مسئولیت‌ها، خوانایی کد و قابلیت نگهداری** طراحی شده است.

```text
src/
├── assets/
│   └── # فایل‌های استاتیک و تصاویر
│
├── Components/
│   └── CurrencyConverter/
│       └── # کامپوننت اصلی تبدیل ارز
│
├── constants/
│   └── # مقادیر ثابت مانند نرخ تبدیل
│
├── types/
│   └── # Typeها و Interfaceهای TypeScript
│
├── utils/
│   └── # توابع محاسباتی و فرمت‌دهی اعداد
│
├── App.tsx
│   └── # کامپوننت اصلی برنامه
│
├── main.css
│   └── # استایل‌های عمومی و متغیرهای CSS
│
└── main.tsx
    └── # نقطه ورود برنامه
```

# 📂 توضیح بخش‌های اصلی پروژه

### `Components`

کامپوننت‌های رابط کاربری در این بخش قرار گرفته‌اند.

کامپوننت اصلی تبدیل ارز نیز در همین قسمت سازمان‌دهی شده است.

هدف این ساختار، کاهش پیچیدگی و ایجاد Componentهای قابل نگهداری و توسعه است.

---

### `constants`

مقادیر ثابتی که در بخش‌های مختلف پروژه مورد استفاده قرار می‌گیرند در این قسمت نگهداری می‌شوند.

برای مثال:

```text
نرخ تبدیل USD → IRR
```

با قرار دادن این مقادیر در یک محل مشخص، از تکرار و Hard-Code شدن آن‌ها در Componentهای مختلف جلوگیری می‌شود.

---

### `types`

تمام Typeها و Interfaceهای TypeScript در این قسمت تعریف می‌شوند.

این جداسازی باعث می‌شود ساختار داده‌ها مشخص و Type-Safe باقی بماند.

---

### `utils`

توابع مستقل مربوط به منطق محاسباتی و پردازش داده در این قسمت قرار گرفته‌اند.

از جمله:

- محاسبه تبدیل ارز
- فرمت‌دهی اعداد
- پردازش مقادیر ورودی

با این ساختار، منطق محاسباتی از لایه نمایش جدا نگه داشته شده است.

---

# 🔄 روند عملکرد تبدیل ارز

روند کلی عملکرد برنامه به شکل زیر است:

```text
ورود مقدار توسط کاربر
        │
        ▼
پردازش مقدار ورودی
        │
        ▼
محاسبه نرخ تبدیل
        │
        ▼
فرمت‌دهی مقدار
        │
        ▼
به‌روزرسانی رابط کاربری
```

تمام این مراحل در سمت Client انجام می‌شوند و نتیجه بدون نیاز به Refresh صفحه نمایش داده می‌شود.
