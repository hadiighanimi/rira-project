# 💱 پروژه تبدیل‌کننده ارز

> یک وب‌اپلیکیشن Front-End مدرن و واکنش‌گرا برای تبدیل دوطرفه دلار آمریکا (USD) و ریال ایران (IRR)، توسعه‌یافته با React، TypeScript و Vite.

---

## 🚀 نحوه اجرای پروژه

### پیش‌نیازها

برای اجرای پروژه در محیط محلی، موارد زیر باید روی سیستم نصب باشند:

* **Node.js**
* **npm**

### 1. دریافت پروژه

```bash
git clone https://github.com/hadiighanimi/rira-project.git
```

### 2. ورود به پوشه پروژه

```bash
cd rira-project
```

### 3. نصب وابستگی‌ها

```bash
npm install
```

### 4. اجرای پروژه در محیط توسعه

```bash
npm run dev
```

پس از اجرای دستور، آدرس پروژه توسط Vite در ترمینال نمایش داده می‌شود.

### 5. اجرای نسخه Production به‌صورت محلی

ابتدا پروژه را Build کنید:

```bash
npm run build
```

سپس نسخه Production را اجرا کنید:

```bash
npm run preview
```

## 📌 معرفی پروژه

**Rira Currency Converter** یک وب‌اپلیکیشن Front-End است که با استفاده از **React، TypeScript و Vite** توسعه داده شده است.

هدف پروژه، پیاده‌سازی یک تبدیل‌کننده ارز ساده و کاربردی است که کاربر بتواند مقدار موردنظر خود را وارد کرده و معادل آن را در واحد ارزی دیگر، بدون نیاز به بارگذاری مجدد صفحه مشاهده کند.

تمرکز اصلی پروژه بر موارد زیر بوده است:

* تجربه کاربری مناسب
* طراحی واکنش‌گرا
* ساختار Component-Based
* Type Safety
* جداسازی منطق محاسباتی از رابط کاربری
* خوانایی و قابلیت نگهداری کد

---

## ✨ قابلیت‌های پروژه

### 🔄 تبدیل دوطرفه ارز

امکان تبدیل در هر دو جهت:

* 💵 **دلار آمریکا (USD) → ریال ایران (IRR)**
* 💴 **ریال ایران (IRR) → دلار آمریکا (USD)**

با تغییر مقدار ورودی، مقدار معادل در واحد ارزی مقابل به‌صورت خودکار محاسبه می‌شود.

### ⚡ محاسبه لحظه‌ای

نتیجه تبدیل با هر تغییر در مقدار ورودی به‌صورت لحظه‌ای به‌روزرسانی می‌شود.

برای مشاهده نتیجه نیازی به موارد زیر نیست:

* Refresh صفحه
* ارسال فرم
* کلیک روی دکمه محاسبه

تمام محاسبات در سمت Client انجام می‌شوند.

### 🔢 فرمت‌دهی اعداد

برای افزایش خوانایی مقادیر، اعداد با جداکننده سه‌رقمی نمایش داده می‌شوند.

```text
1000000
↓
1,000,000
```

### 📱 طراحی واکنش‌گرا

رابط کاربری برای اندازه‌های مختلف صفحه طراحی شده و در موارد زیر قابل استفاده است:

* 💻 دسکتاپ
* 📱 موبایل
* 📟 تبلت

برای پیاده‌سازی Responsive Design از قابلیت‌هایی مانند:

* Flexbox
* CSS Variables
* `clamp()`
* واحدهای نسبی

استفاده شده است.

## 🧩 معماری و ساختار پروژه

ساختار پروژه با هدف **جداسازی مسئولیت‌ها، خوانایی کد و قابلیت نگهداری** طراحی شده است.

```text
src/
├── assets/
│   └── # فایل‌های استاتیک و تصاویر
│
├── Components/
│   └── CurrencyConverter/
│       └── # کامپوننت اصلی تبدیل ارز
│
├── constants/
│   └── # مقادیر ثابت مانند نرخ تبدیل
│
├── types/
│   └── # Typeها و Interfaceهای TypeScript
│
├── utils/
│   └── # توابع محاسباتی و فرمت‌دهی اعداد
│
├── App.tsx
│   └── # کامپوننت اصلی برنامه
│
├── main.css
│   └── # استایل‌های عمومی
│
└── main.tsx
    └── # نقطه ورود برنامه
```

### Components

کامپوننت‌های رابط کاربری در این بخش قرار گرفته‌اند و کامپوننت اصلی تبدیل ارز نیز در همین ساختار سازمان‌دهی شده است.

### constants

مقادیر ثابت مورد استفاده در پروژه، مانند نرخ تبدیل ارز، در این بخش نگهداری می‌شوند تا از Hard-Code شدن مقادیر در Componentها جلوگیری شود.

### types

Typeها و Interfaceهای TypeScript در این بخش تعریف شده‌اند تا ساختار داده‌ها در قسمت‌های مختلف پروژه یکپارچه و Type-Safe باقی بماند.

### utils

توابع مستقل مربوط به منطق محاسباتی و پردازش داده در این بخش قرار گرفته‌اند؛ از جمله:

* محاسبه تبدیل ارز
* فرمت‌دهی اعداد
* پردازش مقادیر ورودی

این ساختار باعث جداسازی منطق برنامه از لایه نمایش می‌شود.

## 🧠 تصمیمات فنی

### جداسازی مسئولیت‌ها

منطق محاسباتی، ثابت‌ها، Typeها و رابط کاربری در بخش‌های جداگانه قرار گرفته‌اند تا توسعه و نگهداری پروژه ساده‌تر باشد.

### Component-Based Architecture

رابط کاربری بر اساس Componentهای مستقل طراحی شده است تا:

* خوانایی کد افزایش پیدا کند.
* نگهداری پروژه ساده‌تر شود.
* توسعه قابلیت‌های جدید آسان‌تر باشد.
* امکان استفاده مجدد از Componentها وجود داشته باشد.

### استفاده از TypeScript

استفاده از TypeScript باعث می‌شود ساختار داده‌ها مشخص باشد و بسیاری از خطاهای مربوط به Type در زمان توسعه شناسایی شوند.

### Responsive Design

برای جلوگیری از وابستگی بیش از حد به اندازه‌های ثابت، از قابلیت‌های Responsive CSS استفاده شده است تا رابط کاربری در اندازه‌های مختلف صفحه عملکرد مناسبی داشته باشد.

### وابستگی‌های محدود

پروژه با وابستگی‌های محدود و متناسب با نیازمندی‌های آن پیاده‌سازی شده تا ساختار پروژه ساده و قابل نگهداری باقی بماند.
